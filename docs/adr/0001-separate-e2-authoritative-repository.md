# Separate E2 into an authoritative repository

AugloE2 is the sole authority for E2 contracts and any extracted E2 Modules while separation is active. AugloAI remains historical upstream context and the eventual destination for deliberate reintegration, but it is not a concurrent authority.

Bidirectional synchronization is rejected because two writable authorities would create ambiguous ownership, hidden divergence, and unsafe reintegration. Changes move through an explicit extraction or reintegration decision instead of automatic mirroring.
